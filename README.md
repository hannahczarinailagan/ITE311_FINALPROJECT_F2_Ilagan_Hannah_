## Project Description

PetBook is a web-based pet care management and appointment booking system for pet grooming shops, veterinary clinics, and pet care businesses.

Pet owners can request appointments and manage pet profiles. The system also provides appointment lists and SMS message previews. The demo version uses JavaScript arrays and does not persist records in a database or send real SMS messages.

Planned features include medical and grooming history, vaccination tracking, staff assignment, service packages, loyalty points, sales reports, automated reminders, and a 10% commission on completed booking transactions.

## How to Run

1. Install XAMPP.
2. Start Apache.
3. Place the PetBook folder inside `C:\\xampp\\htdocs`.
4. Open http://localhost/PetBook/ in your browser.

## Current Limitations

- Appointment and pet records exist only in browser memory.
- SMS messages are previews only and are not sent.
- MySQL database integration and user authentication are not yet implemented.
